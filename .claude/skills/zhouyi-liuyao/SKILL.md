# 周易 · 六爻

以《周易》六十四卦观「势、象、时机」。一条主线：

> **先起准卦、查对经辞，再借象说理。** 卦象不预测事实、不替人拍板；它提供一个沉静的视角，把眼前的事放进阴阳变化里看，落点仍是务实的行动。

草屋用法：占断只是一类答案。问及建议时，与 [[life-decision-guide]] 的循证结论并列列出——**经验怎么说、证据怎么说、卦象怎么说**，三者不互相折算，由人自断。

## 何时用 / 不用

- **用**：用户明确要占卦、问卦象；或问建议/决策时愿意听这一类视角。
- **不用**：八字、紫微、奇门、梅花（不同体系，技法不通）。
- 用户只是闲聊《易经》哲学、要某句卦辞的白话解释——直接讲，不必起卦。

## 起卦（铜钱法）

```bash
node cast.mjs                 # 随机起卦（crypto 真随机）
node cast.mjs 333 233 ...      # 用户亲手摇的六掷（字=2 背=3，初爻在前）
```

输出含：本卦、变卦、动爻位次、每爻 6/7/8/9、卦辞；单动爻时直接附该爻爻辞。

- 用户要自己摇钱：让他掷六次三枚铜钱，按顺序报来，**不要替他随机**——心诚在仪式本身。
- 干支（月建、日辰）脚本只做近似；六爻断卦若在节气交界，提醒以当日真实干支为准。

## 断法一：周易经学（默认，适合问建议）

依朱熹《易学启蒙·考变占》定查哪句经辞：

| 动爻 | 查 |
|---|---|
| 0 | 本卦**卦辞** |
| 1 | 本卦该**动爻爻辞** |
| 2 | 本卦两动爻爻辞，**以上爻为主** |
| 3 | 本卦卦辞（贞/体）＋变卦卦辞（悔/用） |
| 4 | 变卦两静爻爻辞，**以下爻为主** |
| 5 | 变卦唯一静爻爻辞 |
| 6 | 变卦卦辞（乾用「用九」、坤用「用六」） |

**经辞必须查 `data/zhouyi.json` 原文**，64 卦卦辞与全部爻辞都在，不凭记忆引；查不到就说没有。需要白话讲解时，另可查 `data/glossary.json` 术语。

解读口径：

1. 先把经辞原文列出（注明卦名、第几爻），再讲象意——不混在一起。
2. 紧扣用户的事：这一爻说的处境，与他当下哪一步相应。
3. 给出可执行的落点：宜什么、忌什么、等什么时机。不说「你会成功/失败」。
4. 文字克制清淡，一句吉凶了事是最下等的断法。

## 断法二：六爻纳甲（问吉凶旺衰、事有明确月日时）

纳甲法以**月建日辰**对六爻逐爻论生克。排盘交给引擎：

```bash
cd engine
python3 paipan.py --hexagram 地泽临 --moving 2 --month 未 --day 辛卯 --yongshen 妻财
```

起卦结果可直接喂给引擎（卦名＋动爻＋脚本输出的月支/日干支）。引擎输出含六亲、纳甲、六神、世应、空亡、月破日破、暗动、化进化退、入墓。**先核对盘面与题面一致再断。**

断卦八步与全部辨析（暗动 vs 日破、三合虚合、冲墓双向、四神有力无力、反吟伏吟等）：

1. 取用神（占事→六亲，见下；取错全错）
2. 用神旺衰（月建＋日辰同权；旺衰是「有力无力」，不是吉凶方向）
3. 世爻状态（求测者自身）
4. 查动静、暗动、空亡、月破日破
5. 查化进化退、变爻回头生克
6. 查三合六合、墓库
7. 综合定性：用神与世爻的生克为纲，给**有层次、有条件**的结论
8. 定应期：衰待生旺、墓待冲、空待填冲、破待填

详解见 `references/01`～`11`（装卦排盘、用神、旺衰、动静暗破、进退、三合、墓库、断卦步骤、四神、卦变反伏、64 卦判辞），断前按需查阅，不凭印象。

用神速查：父母长辈文书房屋学业→父母；兄弟同辈竞争者→兄弟；子女下属医药→子孙；钱财妻室→妻财；丈夫官职工作考试疾病忧患→官鬼；男占姻缘看妻财、女占看官鬼；无特定六亲看应爻。

## 边界

- 占断的是势与时机，非事实预测；结论须配合现实理性判断，不替代专业意见（医疗、法律、财务大事另请专业人士）。
- 一事可再三占吗？传统口径：不诚不占、不疑不占。卦象参差时，以第一卦为主。
