# 谋事参谋（decision-advisor）智能体配置

输入要做的事情，智能体结合 Obsidian 经验文档库，按「前期准备 → 中期实施 → 后期收尾」三阶段框架，对将面临的问题给出具体判断分析。

## 宗旨（研判总约束）

1. **时间固定**：用户的时间付出是固定的——能用钱、能外包、能由他人承担的事，不占用用户时间。
2. **减少责任**：优先设计责任转移机制（合同、保险、书面确认、第三方担保、验收留痕）。
3. **精力有限**：帮用户定位工作主体——只做只有用户能做的事（关键决策、关键关系、最终验收）。
4. **普适性**：同一套框架适用于各行各业、各类计划。

## 三阶段框架

- **前期准备（15 项）**：相关经验、风险责任、时间安排、预算安排、人员协调、方案确定、高质量交付、风险规避、进度同步、AI 排查、流程想通、工作主体定位、场地、出行、第三方协调。
- **中期实施（4 项）**：物料筹备、设备准备、场地安全、人员安全。
- **后期收尾**：验收结算、场地设备恢复、责任了结、复盘沉淀、关系维护。

## 审查维度（涉设备 / 电路 / 施工必查）

设备风险、电路风险、施工风险、设备替代、耐久性、耐用性、性价比。

## 目录结构

```
decision-advisor/
├─ preset.yml                 # 显示名与描述
├─ agent.cordis.yml           # 组装：人设 + Obsidian MCP + 外部信息检索 + 技能
└─ skills/
   └─ task-analysis/
      └─ SKILL.md             # 三阶段研判工作流技能
```

## 安装与启用

1. 把 `decision-advisor` 整个目录复制到 DSH 的 preset 根目录（`<dshHome>/.agent-presets/decision-advisor`）。
2. 新建会话时选择「谋事参谋」preset（会话一旦产出内容便不可切换）。

## 前置依赖：Obsidian MCP

与「治愈文案师」（../healing-scribe）相同：Obsidian 安装 **Local REST API** 插件、安装 uv（提供 `uvx`）、设置环境变量 `OBSIDIAN_API_KEY`。两个 preset 可共用同一个 Obsidian vault。

## 经验文档约定

经验库放在 vault 的 `经验文档/` 目录，建议「一件事一篇复盘笔记」，frontmatter 示例：

```markdown
---
topic: 家庭装修
tags: [经验, 复盘, 装修, 预算]
阶段: [前期准备, 中期实施, 后期收尾]
审查: [电路, 施工, 性价比]
结果: 有条件成功
date: 2025-10-01
---
```

正文按「背景 / 前期准备 / 中期实施 / 后期收尾 / 审查 / 教训（按宗旨）」组织，参见 `../vault-template/经验文档/家庭装修复盘-示例.md`。

## 使用示例

> 我想在小区门口开一家咖啡店。

智能体会：确认目标与资源 → 检索经验库中开店、装修、证照办理等复盘 → 输出总体判断 + 三阶段研判 + 审查意见 + 用户工作主体定位 + 责任转移方案 + 经验引用 + 无先例部分。
