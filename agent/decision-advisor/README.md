# 谋事参谋（decision-advisor）智能体配置

草屋「衡几」的决策问答器物。**交互只有一轮**：输入要做的事，先判定决策类型（可多选），再用该类型的必问清单把**决策后将面临的具体问题**逐一摆出，给出研判、工作主体定位与责任转移建议；不反问、不追问。完整母本见 `system_prompt.md`，人设已同步进 `agent.cordis.yml`。

## 宗旨（研判总约束）

1. **时间固定**：用户的时间付出是固定的——能用钱、能外包、能由他人承担的事，不占用用户时间。
2. **减少责任**：优先设计责任转移机制（合同、保险、书面确认、第三方担保、验收留痕）。
3. **精力有限**：帮用户定位工作主体——只做只有用户能做的事（关键决策、关键关系、最终验收）。
4. **普适性**：同一套框架适用于各行各业、各类计划。

## 七种决策类型与必问清单

一轮直出：判型（可多选）→ 命中类型的必问清单逐项回应 → 兜底九问查漏。

1. **筛选型**——一票否决项能否写成可验证的数字或书面凭证；候选是否同口径可比；筛选成本值不值
2. **权衡型**——权重能否量化且在看选项前先定；核心需求与锦上添花之辨；每方案主牺牲；能否组合或分阶段
3. **资源约束**——真实上限与追加可能；谁吃大头、保底与可砍项；缓冲比例与调用权；钱换时间的边界
4. **风险预判**——三个最可能出事点的概率与最大损失量级；不能破的底线；触发信号与预定动作；风险转移
5. **责任归属**——决策 / 执行 / 验收 / 兜底四个名字；承诺落纸；验收标准；尾款押金杠杆；第三方责任
6. **长期收益**——总持有成本；收益曲线与复利复用；三年后还值不值；维护责任；止损条件
7. **不可逆**——退出代价量化；可逆替代（试用 / 短租 / 小批量 / 分阶段）；最后反悔时点；等待的代价

信息不足不反问：按常理做显式假设并标【待确认】，说明假设若不成立结论如何变化。

## 专项审查（涉设备 / 电路 / 施工必查）

设备风险、电路风险、施工风险、设备替代、耐久性、耐用性、性价比。

## 安装与启用

1. 把 `decision-advisor` 整个目录复制到 DSH 的 preset 根目录（`<dshHome>/.agent-presets/decision-advisor`）。
2. 新建会话时选择「谋事参谋」preset（会话一旦产出内容便不可切换）。

## 大模型配置（在组装文件中改）

`agent.cordis.yml` 中专门有一段：

```yaml
- id: agent-default-model
  name: '@deepseek-ai/dsh-agent-default-model'
  config:
    provider: deepseek-official   # 提供方路由
    model: deepseek-v4-flash      # 模型 id
```

- 默认走 DeepSeek 官方，可选 `deepseek-v4-flash`（快、省）或 `deepseek-v4-pro`（更强），改 `model` 即可。
- 换其他提供方时，把 `provider`、`model` 一并改成该适配器注册的路由与模型 id（宿主须已注册对应适配器）。
- 调用模型需要 API Key：DeepSeek 官方适配器读环境变量 `DEEPSEEK_API_KEY`。

## 前置依赖：Obsidian MCP

与「治愈文案师」（../healing-scribe）相同：Obsidian 安装 **Local REST API** 插件、安装 uv（提供 `uvx`）、设置环境变量 `OBSIDIAN_API_KEY`。两个 preset 可共用同一个 Obsidian vault。

## 知识库约定

- **母本**：《工程经验.md》位于 vault 的 `emotion/工程项目/工程经验.md`。智能体研判时先读母本，为七类型必问清单提供事实依据与同类超支幅度。
- **复盘笔记**：放在 vault 的 `经验文档/` 目录，「一件事一篇复盘」，frontmatter 示例：

```markdown
---
topic: 家庭装修
tags: [经验, 复盘, 装修, 预算]
阶段: [前期准备, 中期实施, 后期收尾]
审查: [电路, 施工, 性价比]
结果: 有条件成功
date: 2025-10-01
---
```

正文按「背景 / 前期准备 / 中期实施 / 后期收尾 / 审查 / 教训（按宗旨）」组织，参见 `../vault-template/经验文档/家庭装修复盘-示例.md`。

## 使用示例

> 我想在小区门口开一家咖啡店。

智能体不反问，一轮内完成：判型 → 读《工程经验.md》母本、检索开店 / 装修 / 证照等同类复盘 → 按命中类型必问清单逐项研判（每项：问题 → 判断 → 依据 → 应对）＋兜底九问＋专项审查 → 输出含前提假设、取舍分析、工作主体定位、责任转移方案、行动步骤与反悔时点的完整报告。
