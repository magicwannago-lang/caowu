# 治愈文案工作流

## 何时使用

用户表达情绪困扰、需要被安慰或开解，或明确要求「治愈文案 / 疗愈文字 / 用儒释道智慧写一段话 / 随机来几条」时，调用本技能。

## 标准流程

1. **定题**：用户有困扰 → 在《心理问题/现代人心理问题汇总.md》定位条目；未指定 → 随机抽一条并告知。
2. **澄清**：体裁、受众、语气、条数。缺失且影响成稿时一次性问清；用户想直接看稿则用默认（朋友圈短文 / 温柔克制 / 一条）。
3. **取典**：在「儒释道典籍」中检索原文，一家为主。原文须在笔记中查得到；查不到则转述义理，不编造。
4. **时事**：先查「时事」目录；暂无合适条目时网页检索近期真实现象，注明日期与来源。
5. **三重印证**：心理问题 → 典籍智慧 → 时事共鸣，交集成立再写；凑不上的素材不用。
6. **成稿**：按下表体裁输出；默一条，用户要多条则给三条不同角度、各自可发。
7. **归档**：询问是否存入「治愈文案」目录，确认再写。
8. **边界**：危机信号（自伤、自杀）时停止创作，温和回应并引导专业援助（热线 12356）。

## 体裁规格

| 体裁 | 篇幅 | 构成 |
| --- | --- | --- |
| 公众号长文 | 600–900 字 | 标题 + 正文（可两个短小标题），典故事融入叙述，不堆引文 |
| 朋友圈 / 小红书短文 | 150–300 字 | 一个画面切入，收在一个可做的小动作上；可有一短标题 |
| 卡片金句 | 20–60 字 | 一句即可，不写解释；须能独立成立，不做格言拼凑 |

多条（三条）时：每条各自完整、角度不同（如一条承认情绪、一条典籍视角、一条日常落点），不要同一句话换三种说法。

## 输出模板

单条：

```
【标题】<可为空，卡片金句不需要>
<正文>

【出处】
- 心理问题：<总表条目，板块·序号>
- 典籍：<书名·篇名>「<原文短句>」
- 时事：<条目标题或检索来源，日期>
```

三条：

```
一、<标题>
<文案>

二、<标题>
<文案>

三、<标题>
<文案>

【共同出处】
- 心理问题：…
- 典籍：…
- 时事：…
```

「出处」是给用户核对的底稿，不写进发布文案；引用原文完整列出。

## 写作红线

- 先承认痛苦，再给路；不鸡汤、不口号、不说教、不硬升华。
- 克制清淡、有画面感；术语点到即止；不玄幻、不拜金、不贩卖焦虑。
- 不确定的原文不引用；时事不造假、不蹭灾难。

## 典籍速查（按库存笔记）

| 困扰类型 | 侧重 | 库存笔记 | 常见切入 |
| --- | --- | --- | --- |
| 人际冲突、责任过重、讨好 | 儒家 | 儒家/论语、孟子、大学、中庸 | 己所不欲勿施于人、反求诸己、文质彬彬 |
| 逆境、失败、自我怀疑 | 儒家 | 儒家/孟子 | 天将降大任、生于忧患 |
| 内耗、执着、过度用力、攀比 | 道家 | 道家/道德经（第八章、选章）、庄子 | 上善若水、知足不辱、柔弱胜刚强、安之若命 |
| 拖延、畏难、焦虑失序 | 儒/道 | 大学、道德经第六十三章 | 知止有定、难事作于易 |
| 焦虑、恐惧、失去、无常 | 佛家 | 佛家/心经、金刚经 | 心无挂碍、应无所住、凡所有相皆是虚妄 |
| 念头纷飞、与情绪对抗 | 佛家 | 六祖坛经、道德经第十六章 | 看见客尘、致虚守静 |
| 「想自洽却更内耗」 | 儒/佛 | 中庸、六祖坛经 | 发而中节、本来无一物 |
