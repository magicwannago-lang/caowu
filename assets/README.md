# 藏品图片与音频

两个目录的内容都**不写死在网页里**：跑一次清单脚本，页面读清单。

```bash
python3 scripts/gen-manifest.py
```

它扫一遍 `assets/audio/` 与 `assets/img/`，写出 `assets/manifest.json`。
上传、改名、删除之后跑一次即可——网页本身列不了目录。

输出是稳定的（按文件名排序、不写生成时间），所以没变的时候 git 里看不出改动。

## 补标题与说明

两个目录里各可以放一个 `_meta.json`，按文件名补元信息：

```json
{
  "01-远山.jpg": { "title": "远山", "note": "雾起于山腰", "alt": "淡青的远山" },
  "02-疏影.jpg": { "title": "疏影" },
  "雨落草檐.mp3": { "title": "雨落草檐", "sub": "檐下流水" }
}
```

- 音频：`title`（曲名）、`sub`（副题/时长）
- 图片：`title`、`note`（说明）、`alt`（无障碍描述）、`wide: true` 强制走横长陈位
- 任一目录里 `{ "skip": true }` 表示某个文件不进清单（草稿、原始素材）

文件名以 `_` 或 `.` 开头的文件一律不进清单，`_meta.json` 自身也是。

## 图片 `assets/img/`

不用改 HTML，清单里有什么就陈列什么。第一幅（或 `"wide": true` 的那幅）
走横长陈位，其余按 4:3 依序摊开。

| 位置 | 比例 | 建议像素 |
|---|---|---|
| 横长陈位（`.relic-wide`） | 21 : 9 | 1600 × 686 |
| 普通陈位 | 4 : 3 | 1200 × 900 |

宽高比大于 2 的图自动归入横长陈位（清单脚本会读 JPEG 头部判断）。
图片一律 `object-fit: cover` 裁切，带极缓的悬停放大 1.025 倍。

**色调建议**：偏浅、低饱和，与米白纸底相处。过艳的图片会破坏整页的纸感。

## 音频 `assets/audio/`

清单一有曲目，底部听音条就能用了：上一首 / 播放暂停 / 下一首、
可拖动的进度、音量，播完自动接下一首。刷新后记得上次听到哪一首
（`localStorage`），但不自动起声——浏览器政策如此，也合礼数。

支持的格式：`mp3` `m4a` `aac` `ogg` `oga` `opus` `wav` `flac`。

观隅那枚按钮是入口，真正的控件固定在屏底（`.listener`）——
曲目信息与播放键要跟着人走，划到哪儿都能控。

**曲目起声时，合成的雨声会自动让位**（`Ambient.duck()`），不用手动去关。
