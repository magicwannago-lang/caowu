```bash

fuser -k 8000/tcp
/root/.venvs/job_assi/bin/python /root/workspace/caowu/agent/job_assi/main.py &
# 静态站（验收用）：仓库根 python3 -m http.server 8123

```

- Python venv 在仓库外 `/root/.venvs/job_assi`（系统 Python 3.12 PEP668 禁装，
  apt 装了 python3.12-venv；fastapi 0.162 / uvicorn 0.54 / pydantic 2.14）。

  线上页面连的是访客自己机器上的后端。后端骨架内存存储，重启即清空；
  LLM 解析 / 真实站点抓取 / 自动投递均为 mock，待后续接。
