# D16.14 · 反馈④：五色分区立重点 + 按钮重叠根治

用户两条意见：
1. 整体太平、素雅但缺对比，重点不敏锐 → 用多彩配色逐步突出差异
2. 大儒呈作按钮有重叠（开始/呈作中），按钮逻辑乱，何时能下载要明确

## 一、五色矿物，分区各领一色（低饱和，不破宋雅）

`styles/tokens.css`：在灰青、赭石之外新增黛蓝、藕紫、黛绿，
每色配 soft（悬停加深）/ mist（只用于面，不用于字）两档；
新加 `--accent / --accent-soft / --accent-mist` 间接层，默认灰青。

## 二、按钮重叠的根因与修复

根因：作者样式 `.btn { display:inline-block }` 与 UA 的
`[hidden]{display:none}` 同特异性，作者样式后到 → 带 hidden 的按钮
（下载/确认）照样渲染，于是多个状态的按钮同时可见、互相重叠。

修复（base.css 顶部）：

```css
[hidden] { display: none !important; }
```

一处根治，不靠逐个按钮补类。

## 三、状态逻辑显性化

- `index.html`：提示行加 `#book-hint`（动态）；确认按钮缩短为「确认并呈作」
- `.tool-foot / .tool-acts` 加 flex-wrap，窄屏按钮自然换行不挤叠
- `scripts/book.js` 在每个状态 setHint：
  - idle：先呈蓝图 · 确认后动笔
  - blueprinting：大儒正在擘画蓝图…
  - awaiting：蓝图已呈；确认后动笔，不合意可重新擘画
  - working：大儒正在著书；**定稿成卷后方可下载**
  - stopped：管线中断于此；点「续上未竟之章」接着写
  - finalizing：大儒正在定稿；定稿成卷后方可下载
  - done：**已成卷，可点「下载书卷」**；「再呈一部」另起新卷
