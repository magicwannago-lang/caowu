# K15.20 · 修复「寻思帖图片不能生成」：超时误杀，已加固并 6/6 实测通过

用户反馈：寻思（discuss）的图片不能生成。

## 一、定位

- 直连线上 SSE 连测：6 次中 5 次成功，1 次顶层 `{t:'error'}`——
  消息 "The operation was aborted due to timeout"，是 **makePlan 起语阶段
  撞上 SAYING_TIMEOUT_MS 90s**（高峰期模型斟酌久，寻思体性更甚），整帖被判失败，
  图自然没有。图片阶段 60s 上限对 2560×1440 高分辨率也偏紧。
- 前端看门狗无责：心跳 ping 走 handle()→arm()，12s 一续，不会误断。

## 二、修复（仅 worker/src/daily.js）

1. `IMAGE_TIMEOUT_MS` 60s→90s；
2. 新增 `withRetry(fn, tries=2)`：起语 rawCall、配图 makeImage 各失败重试一次
   （新连接；高峰时限流/超时重试常即通）。SSE 心跳贯穿，等待期间前端不断连；
3. 图片失败原有降级路径不变（重试都败才发 warn、保文字）。

部署 Version ID `8328622e`。

## 三、验证

部署后连测 6 帖寻思＋配图：**6/6 全部 image OK 且 done 齐**。

代价：最坏情况起语/配图各两试，单帖等待可能拉长，但阶段提示与心跳都在，
不再「直接无图」。
